Data Types

Detailed technical documentation of all QStorage API endpoints, request/response formats, and example implementations.

AbortIncompleteMultipartUpload

Specifies the days since the initiation of an incomplete multipart upload that QStorage will wait before permanently removing all parts of the upload.

AnalyticsFilter

Container for the filter used to describe a set of objects for analyses. A filter must have exactly one prefix, one tag, or one conjunction (And).

BucketLoggingStatus

Root level tag for the BucketLoggingStatus parameters.

BucketPolicy

Container for the bucket policy.

Bucket

Container for bucket information.

CompletedPart

Details of the parts that were uploaded.

Condition

Container for describing a condition that must be met for the specified redirect to be applied.

CopyObjectResult

Container for response elements from a CopyObject operation.

CORSRule

Specifies a cross-origin access rule for a bucket.

DefaultRetention

The default Object Lock retention settings for new objects placed in the specified bucket.

ErrorDetails

The ErrorDetails data type contains information about errors that occurred during an operation.

ErrorDocument

Container for the object key name to use when a 4XX class error occurs.

Grant

Container for grant information.

Grantee

The person being granted permissions.

IndexDocument

Container for the suffix configuration of the website index document.

Initiator

Container element that identifies who initiated the multipart upload.

LifecycleExpiration

Specifies the expiration for the lifecycle of the object in the form of date, days and, whether the object has a delete marker.

LifecycleRuleAndOperator

This is used in a Lifecycle Rule Filter to apply a logical AND to two or more predicates. The Lifecycle Rule will apply to any object matching all of the predicates configured inside the And operator.

LifecycleRuleFilter

The Filter is used to identify objects that a Lifecycle Rule applies to. A Filter must have exactly one of Prefix, Tag, or And specified.

LifecycleRule

A lifecycle rule for individual objects in a QStorage bucket.

LoggingEnabled

Describes where logs are stored and the prefix that QStorage assigns to all log object keys for a bucket.

MetadataTableConfigurationResult

The MetadataTableConfigurationResult data type contains the result of a metadata table configuration operation. This data type is used to represent the output of operations that configure or modify metadata table settings.

MetadataTableConfiguration

The MetadataTableConfiguration data type contains information about the metadata table configuration for a bucket.

NoncurrentVersionExpiration

Specifies when noncurrent object versions expire. Upon expiration, QStorage permanently deletes the noncurrent object versions. You set this lifecycle configuration action on a bucket that has versioning enabled (or suspended) to request that QStorage delete noncurrent object versions at a specific period in the object's lifetime.

ObjectLockRule

Container for the Object Lock rule for the specified object.

Object

An object consists of data and its descriptive metadata.

Owner

Container for the bucket owner's information.

OwnershipControlsRule

Container for a rule that defines ownership controls.

OwnershipControls

Container for ownership controls.

Part

A container for information about a part of a multipart upload.

PolicyStatus

Container for the policy status of a bucket.

RedirectAllRequestsTo

Container element that specifies the redirect behavior of all requests to a website endpoint of a bucket.

Redirect

Container element that provides instructions for redirecting the request.

RoutingRule

Container for one routing rule that identifies a condition and a redirect.

Rule

Specifies lifecycle rules for a QStorage bucket. For more information, see PutBucketLifecycle.

S3TablesDestinationResult

The S3TablesDestinationResult data type contains information about the destination table for metadata.

ServerSideEncryptionRule

The ServerSideEncryptionRule data type specifies the default server-side encryption configuration for a bucket.

Statement

Container for a policy statement.

Tag

Container for a tag key and value.

Tagging

Container for the tag set.

Transition

Specifies when a QStorage object transitions to a specified storage class.

UploadPart

Uploads a part in a multipart upload.

VersioningConfiguration

Container for bucket versioning configuration.

WebsiteConfiguration

Container for all website configuration elements.
